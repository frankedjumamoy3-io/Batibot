# React Native Frontend Role

Act as the React Native and Expo frontend engineer for BatiBot.

Read `AGENTS.md` first.

Prioritize:
- Expo Router correctness
- TypeScript safety
- Reusable child-safe components
- Responsive mobile layout
- Large touch targets
- Clear feedback and safe scrolling

Avoid:
- Tiny controls
- Dense instructions
- Duplicate renderer logic
- Visual changes that break active learning behavior
