# Test One Learner Flow

Read `AGENTS.md` first and follow it as the source of truth.

Flow:
`Play` -> select level -> select world -> select topic -> `LOOK` -> `TAP` -> `TRY` -> `CHOOSE` -> `PLAY` -> reward -> progress -> mastery

Check:
- Navigation and unlock state
- Stage completion gates
- Speaker/instruction text matches visible UI
- Correct and wrong answer feedback
- XP, stars, progress save, and reward state
- 2-choice or 4-choice enforcement
- Screen layout on mobile-size viewport
- Broken or missing assets

Do not edit during the first pass. Report bugs and propose the smallest fix plan first.

Return bugs with:
1. Bug
2. Location
3. Severity
4. Cause
5. Fix
